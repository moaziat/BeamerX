# Bundled fonts

`lmsans10-regular.otf`, `lmsans10-bold.otf`, `lmsans10-oblique.otf`, and
`lmsans10-boldoblique.otf` are **Latin Modern Sans 10**, version 2.004,
Copyright 2003, 2009 B. Jackowski and J. M. Nowacki (on behalf of TeX users
groups). They are redistributed unmodified under the GUST Font License:
<http://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt>.

BeamerX embeds them so that text in the editor uses the same font face and
metrics as text in the exported Beamer document. Latin Modern Sans is the
default sans-serif text font of LaTeX under XeTeX/LuaTeX/Tectonic, and its
design is essentially identical to Computer Modern Sans used by pdfLaTeX.
